A simple 3D renderer using Vulkan and Vulkan Memory Allocator. Uses latest Vulkan features as much as I can.

Currently:
- Vulkan 1.4 for rendering
- VMA for memory allocation
- TinyGLTF for GLTF-scene loading
- Timeline semaphore and "Frames in Flight"
- Dynamic rendering
- Indirect drawing
- Vertex pulling
- etc
